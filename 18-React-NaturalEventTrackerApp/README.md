# Natural Event Tracker

> Tracking natural events via external APIs.

![Project Status](https://img.shields.io/badge/Status-Completed-success) 
![Tech Stack](https://img.shields.io/badge/Tech-React-blue)

## Features

- Fetching real-time event data.
- Map/List visualization.
- Filtering events.

## Technologies Used

- **React**
- **External APIs**
- **JavaScript**

## Getting Started

### Prerequisites
Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation & Execution
1. Clone the repository or download the project files.
2. Navigate to the `18-React-NaturalEventTrackerApp` folder.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm start
   # or npm run dev (if using Vite)
   ```
