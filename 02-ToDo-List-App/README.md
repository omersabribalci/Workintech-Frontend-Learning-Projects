# To-Do List App

> A simple, intuitive task manager built with vanilla web technologies to practice DOM manipulation and local storage.

![Project Status](https://img.shields.io/badge/Status-Completed-success) 
![Tech Stack](https://img.shields.io/badge/Tech-HTML%20|%20CSS%20|%20JS-blue)

## Features

- **Add, Edit, and Delete Tasks:** Fully functional task management.
- **Task Status:** Mark tasks as completed or pending.
- **Dynamic Progress Bar:** Visual progress tracking that updates automatically.
- **Local Storage:** Tasks are saved in the browser so you don't lose them on refresh.
- **Animations:** Visual effects trigger when all tasks are completed.

## Technologies Used

- **HTML5:** Semantic structure.
- **CSS3:** Custom styling, flexbox, and smooth transitions.
- **JavaScript (ES6+):** Logic, event handling, and LocalStorage integration.

## Getting Started

### Prerequisites
You only need a modern web browser (Chrome, Firefox, Edge, Safari, etc.) to run this project.

### Installation & Execution
1. Clone the repository or download the project files.
2. Navigate to the `02-ToDo-List-App` folder.
3. Open the `index.html` file directly in your browser.
   - *Tip:* If you use VS Code, you can use the **Live Server** extension for a better development experience.

## Usage

- **Add a Task:** Type your task in the input field and press **Enter** or click the **Add** button.
- **Edit a Task:** Click the edit icon/button on a specific task to modify its text.
- **Complete a Task:** Check the box next to a task to mark it as done. Watch the progress bar fill up.
- **Delete a Task:** Click the delete (trash) icon to remove a task permanently.
