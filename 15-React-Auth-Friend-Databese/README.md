# Friend Database

> Friend database application with simulated authentication.

![Project Status](https://img.shields.io/badge/Status-Completed-success) 
![Tech Stack](https://img.shields.io/badge/Tech-React-blue)

## Features

- Protected routes.
- Simulated auth flow.
- CRUD operations on friends list.

## Technologies Used

- **React**
- **JavaScript**
- **React Router**

## Getting Started

### Prerequisites
Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation & Execution
1. Clone the repository or download the project files.
2. Navigate to the `15-React-Auth-Friend-Databese` folder.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm start
   # or npm run dev (if using Vite)
   ```
