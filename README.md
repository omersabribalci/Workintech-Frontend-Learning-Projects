# Frontend Learning Projects

Welcome to my **Frontend Learning Projects** repository.

This repository contains a collection of projects I built to learn and practice modern frontend development technologies, starting from basic HTML/CSS/JavaScript and advancing to complex React applications.

## Technologies & Tools

Here are some of the core technologies used across the projects:
- **Core:** HTML5, CSS3, JavaScript (ES6+)
- **Framework/Library:** React.js
- **Styling:** CSS-in-JS, Tailwind CSS
- **Testing:** Cypress (E2E), React Testing Library
- **State Management & Routing:** Context API, React Router
- **Data Fetching:** TanStack Query (React Query)

## How to Run

Most React projects can be run locally by navigating to their folder and using:

```bash
npm install
npm run dev
# or npm start depending on the bundler (Vite vs CRA)
```

For plain HTML/JS projects, you can simply open the `index.html` file in your browser or use an extension like **Live Server** in VS Code.
